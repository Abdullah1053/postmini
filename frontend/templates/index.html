🤖 Reusable AI Conversion Prompt

Copy this prompt into ChatGPT, Claude, Gemini, or any LLM alongside your Postman export, OpenAPI specification, or cURL list to convert it cleanly into PostMini JSON:

You are an API conversion assistant. Convert the provided API endpoints/collection (Postman, OpenAPI, cURL, or documentation) into the clean PostMini collection format. Output ONLY a valid JSON object matching this exact schema: { "name": "", "base_url": "", "requests": [ { "name": "", "method": "GET | POST | PUT | DELETE | PATCH", "url": "", "headers": [ {"key": "Header-Name", "value": "Header-Value", "enabled": true} ], "params": [ {"key": "query_param_key", "value": "query_param_val", "enabled": true} ], "body_type": "none | raw_json | form_data", "body_raw": "", "body_form": [ {"key": "field_name", "value": "field_val", "enabled": true} ] } ] } Conversion Rules: 1. Extract repeating hostnames into "base_url" and reference them in URLs as "{{baseUrl}}/path". 2. If the request has a JSON body, set "body_type": "raw_json" and place formatted JSON in "body_raw". Ensure a "Content-Type": "application/json" header is included. 3. If the request has form fields, set "body_type": "form_data" and place fields in "body_form". 4. Do not include markdown formatting or commentary outside of the JSON block. Here is the API collection/endpoints to convert: [PASTE YOUR POSTMAN COLLECTION / CURL / SPEC HERE]

⚡ Direct Postman v2.0 / v2.1 Import

PostMini also has a built-in Postman parser! You don't even have to convert standard Postman files:

  • In Postman, click on your collection > Export > Collection v2.1 (recommended).
  • Click 📥 Import in PostMini, choose the .json file (or paste its content), and click Import Collection.
  • PostMini automatically flattens folders, preserves URLs, query params, headers, and bodies!
